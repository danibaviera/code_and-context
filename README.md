# code_and_context

> Repositório de estudos, projetos e artigos técnicos em engenharia de dados, arquitetura de software e technical writing.

---

## 🇧🇷 Português

Este repositório reúne projetos práticos desenvolvidos com foco em **engenharia de dados**, **design de arquiteturas** e **escrita técnica de qualidade**. Cada projeto documenta decisões arquiteturais, trade-offs e implementações técnicas aplicadas a domínios de negócio reais — escritos para serem compreensíveis tanto por times de engenharia quanto por stakeholders de negócio.

### Projetos

#### [engineering-writing-lab](./engineering-writing-lab/)

Portfolio de technical writing em engenharia de dados. Dois estudos de caso arquiteturais completos, cobrindo ingestão, transformação, modelagem, serving e governança de dados em domínios distintos.

| Projeto | Domínio | Stack |
|---|---|---|
| [Plataforma de Dados para Retail de Beleza](./engineering-writing-lab/beauty-retail-data-platform/article.md) | Varejo / Cosméticos | Python · Airflow · dbt · Kafka · PostgreSQL |
| [Arquitetura de Dados para Energia Renovável](./engineering-writing-lab/renewable-energy-data-platform/article.md) | Energia / Regulatório | Python · Kafka · Spark · Airflow · Grafana |

Cada artigo cobre:
- Contexto e dores de negócio
- Requisitos funcionais e não funcionais
- Decisões arquiteturais com justificativas explícitas
- Trade-offs mapeados
- Implementação técnica com trechos de código ilustrativos
- Observabilidade, qualidade de dados e governança
- Impacto mensurável para stakeholders
- Roadmap de evolução

## 🇺🇸 English

This repository contains practical projects focused on **data engineering**, **architecture design**, and **quality technical writing**. Each project documents architectural decisions, trade-offs, and technical implementations applied to real business domains — written to be accessible to both engineering teams and business stakeholders.

### Projects

#### [engineering-writing-lab](./engineering-writing-lab/)

A technical writing portfolio in data engineering. Two complete architectural case studies covering ingestion, transformation, modeling, serving, and data governance across distinct domains.

| Project | Domain | Stack |
|---|---|---|
| [Beauty Retail Data Platform](./engineering-writing-lab/beauty-retail-data-platform/article.en.md) | Retail / Cosmetics | Python · Airflow · dbt · Kafka · PostgreSQL |
| [Renewable Energy Data Architecture](./engineering-writing-lab/renewable-energy-data-platform/article.en.md) | Energy / Regulatory | Python · Kafka · Spark · Airflow · Grafana |

Each article covers:
- Business context and pain points
- Functional and non-functional requirements
- Architectural decisions with explicit justifications
- Mapped trade-offs
- Technical implementation with illustrative code snippets
- Observability, data quality, and governance
- Measurable stakeholder impact
- Evolution roadmap
